## Changes

Adds a local comparison of the model output with `main`, so that each following bug-fix PR documents its effect on the results (figures and table below, generated by `tools/compare_branches.bat`). No model code is changed.

- `test_data/`: four test cases, 2012 and 2019 at DY2 and KAN_L, extracted from `CARRA_at_AWS.nc`.
- `tools/test_runs/run_test_cases.py`: runs one model version on all test cases (no spin-up, constant Tdeep = 263 K).
- `tools/test_runs/compare_runs.py`: summary table, figures (cumulative melt/SMB, runoff/refreezing, and LWC profiles with their difference) and PR description template.
- `tools/compare_branches.py` and `tools/compare_branches.bat`: run the comparison locally between `origin/main` and the working tree; results go to `docs/PR_results/<date>_<name>/`.
- `.gitignore`: allow `test_data/*.nc` and `docs/PR_results/**/*.png`.
- README: new section "Testing changes against main".

As expected, the output is identical to `main`.
